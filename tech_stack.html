03 Front-end Details

Styling

  • Hand-written CSS with custom properties (e.g. --scale for fluid hero sizing)
  • Media queries for desktop / tablet / mobile — verified at 1440px and 390px
  • Design tokens: blush pink, cream, muted rose, warm brown; rounded image cards

Typography

Google Fonts CDN:

  • Cormorant Garamond — Latin display
  • Noto Serif TC — Traditional Chinese
  • LXGW WenKai TC — Traditional Chinese

Icons & Imagery

  • Inline SVG sprite (<symbol> + <use>) — no icon library
  • Optimized WebP photography; hero uses fetchpriority="high"
  • loading="lazy" on all below-fold images

Interactivity

  • Native <dialog> + showModal() for search, collections, info popups
  • Event delegation via data-* attributes
  • Client-side search over an in-file product array
  • Favorites in localStorage (bloom-city-favorites)
  • Hamburger nav + CSS dropdowns with aria-expanded state
  • Toast via aria-live; local-only newsletter feedback

Platform Artifacts

Manus

  • manus-routes.json — route manifest for the Manus preview host (one route: /)
  • app.config.ts — platform config (logo URL); the page draws an inline flower mark instead

04 Development & QA

Serve locally

Static server for public/ (threaded — see note below).

python3 -m http.server 8000 --directory public

JS syntax check

Parse-only validation, no linter config needed.

node --check public/app.js

Asset / reference check

HTTP-probe every local src, href, and CSS url() reference for 200s.

Render audit

Headless Chrome via CDP: broken images, console errors, horizontal overflow, font load.

Screenshots

Headless Chrome Page.captureScreenshot — full-page, dialogs, and mobile widths.

!
Local server note: the default single-threaded http.server intermittently drops concurrent requests (ERR_SOCKET_NOT_CONNECTED), breaking lazy-loaded images. Run a ThreadingHTTPServer instead.

05 Known Limitations

Unconnected Actions

  • Contact details, WhatsApp number, and newsletter provider are not connected
  • All such actions are labeled demonstration-only in the UI

Front-end Only

  • Favorites, search, and subscription flows are front-end only
  • No orders are created — no checkout or payments, per scope
